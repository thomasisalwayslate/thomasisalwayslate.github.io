Doom easter egg
===============

Original, unmodified Doom v1.9 shareware episode by id Software.
This is NOT the secretly modified benchmark target.

Distribution source (idgames archive):
https://www.gamers.org/pub/idgames/idstuff/doom/doom19s.zip

shareware-v1.jsdos contains every file from the installed shareware distribution,
plus the original unmodified installer archive at ORIGINAL/DOOM19S.ZIP.
The only additions are the .jsdos emulator configuration.
No game code, levels, graphics, sound or documentation was changed.

Touch controls are provided by the website through the player command interface.

Player: js-dos, loaded from its official CDN only when the reader opens the game.
https://js-dos.com/player-api.html
https://js-dos.com/mobile-support-v7.html
The player and emulator are not bundled into this website's source code.
